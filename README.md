Sales & E-Commerce Overview Dashboard 📊

This project is an interactive Sales & E-Commerce Overview Dashboard created using Power BI as part of the Future Interns Task-3 Internship Program.

The dashboard provides detailed insights into:

Sales Performance
Customer Insights
Product Performance
Revenue Trends
Conversion Funnel Analysis
Brand Contribution Analysis

🎯 Project Objectives

The main objective of this dashboard is to:

Analyze ecommerce sales performance
Track customer activity and transactions
Identify top-performing brands/products
Understand customer conversion behavior
Create an interactive business intelligence dashboard

📈 Key Insights
Apple generated the highest revenue contribution.
Customer activity is very high with 42M transactions.
Most users only view products, while fewer complete purchases.
Revenue trends show overall business growth.
Conversion funnel highlights opportunities to improve cart-to-purchase conversion.
